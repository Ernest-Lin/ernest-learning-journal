# TV Maze 剧集数据分析项目

## 项目概述

本项目是INT303课程的作业，通过爬取TV Maze网站的200部剧集数据，进行深入的数据分析和可视化，探索影响剧集成功的关键因素。

## 文件结构

```
INT303_CW/
├── web_scraping.py          # 网页爬取脚本
├── data_analysis.ipynb      # Jupyter Notebook数据分析报告
├── ernest_lin_123456.csv    # 爬取的数据文件（运行后生成）
├── requirements.txt         # Python依赖包
└── README.md               # 项目说明文档
```

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 数据爬取

运行爬取脚本获取200部剧集数据：

```bash
python web_scraping.py
```

这将生成 `ernest_lin_123456.csv` 文件，包含以下字段：
- 标题 (title)
- 首播日期 (first_air_date)
- 完结日期 (end_date)
- 评分 (rating)
- 类型 (genres)
- 状态 (status)
- 播出网络 (network)
- 简介 (summary)
- 以及其他扩展字段

### 2. 数据分析

打开Jupyter Notebook进行数据分析：

```bash
jupyter notebook data_analysis.ipynb
```

## 研究问题

1. **剧集类型是否影响评分？** - 分析不同题材类型的平均评分差异
2. **播出时间对剧集质量的影响** - 探索首播年份与评分的关系
3. **剧集状态与评分的关联性** - 比较正在播出和已完结剧集的评分差异
4. **地区文化对剧集类型偏好的影响** - 分析不同国家/地区的剧集类型分布
5. **剧集长度与观众满意度的关系** - 探索单集时长对评分的影响

## 技术特点

- **数据源**: TV Maze API (http://api.tvmaze.com)
- **爬虫技术**: Python requests + 正则表达式
- **数据分析**: pandas, numpy, scipy
- **可视化**: matplotlib, seaborn
- **统计方法**: 描述性统计、相关性分析、回归分析、ANOVA检验

## 主要发现

通过分析200部剧集数据，我们发现：

1. 不同剧集类型在评分上存在显著差异
2. 首播年份与剧集质量存在一定关联
3. 剧集状态（正在播出vs已完结）影响评分分布
4. 不同地区对剧集类型有不同偏好
5. 剧集时长与观众满意度存在相关性
