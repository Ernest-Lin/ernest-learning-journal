# Data Availability Statement

This repository provides replication code, empirical outputs, and thesis figures for the project.

Several inputs used in the empirical analysis are derived from WRDS/CRSP mutual fund data. These files are not redistributed publicly because WRDS/CRSP data are subject to institutional licensing restrictions. In particular, the following local files are intentionally excluded from version control:

- `processed_data/holdings_2020_2025_h3.parquet`
- `processed_data/panel_ctrl_h1_h2.csv`
- `processed_data/fundno_portno_map.csv`
- binary model objects in `results/*.pkl`

The notebooks describe how these files enter the empirical workflow. Users with appropriate WRDS/CRSP access can reconstruct the restricted inputs following the data description in the thesis methodology chapter.
